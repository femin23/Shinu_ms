# Shinu M. S. — Author & Storyteller Official Website

Official author portfolio and showcase website for **Shinu M. S.**, author of the *Jahanna* dark fantasy series (*Jahanna: The Rise of Martha* and *Jahanna 2: Life of Evil*) and part of the **Era Universe**.

## 📖 Features

- **Cinematic Hero**: Full-bleed background video presentation with atmospheric sound and visual styling.
- **Atmospheric Particle Canvas**: Ambient crimson ember particles rendered in real-time via HTML5 Canvas.
- **Book Showcases**:
  - *Jahanna: The Rise of Martha* (The Birthplace of All Sins) — Purchase links (BookBangTheory), audiobook stream (Storytel), and detailed lore modals.
  - *Jahanna 2: Life of Evil* — Direct WhatsApp pre-order integration and synopsis.
- **The Era Universe**: Lore exploration of the pioneering Malayalam shared literary universe.
- **Interactive Modals**: Detailed book specifications, author biography, and contact modal with automated mail composition.
- **Archive Search**: Real-time client-side search across book titles, lore, editions, and topics.
- **Responsive Design**: Mobile-first responsive layout with custom Gothic typography and navigation drawer.

## 🛠️ Tech Stack

- **HTML5**: Semantic document structure and embedded video
- **CSS3**: Custom properties, dark fantasy crimson palette, glassmorphism, responsive media queries
- **JavaScript (ES6+)**: Vanilla interactive controllers (modals, search indexing, canvas particle engine, scrollspy)
- **Typography**: Cinzel, Cormorant Garamond, Montserrat, Pinyon Script, Caveat via Google Fonts

## 🚀 Getting Started

Simply open `index.html` in any modern web browser, or serve it with a lightweight static server:

```bash
# Python
python -m http.server 8000

# Node.js
npx serve .
```

Then visit `http://localhost:8000`.
